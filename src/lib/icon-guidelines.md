# Icon Usage Guidelines - Du Lịch Việt

## ✅ ALLOWED Icon Usage (Professional Standard)

### 🎯 Essential Icons Only (20 total maximum)

1. **Navigation Core** (4 icons)
   - `menu` - Mobile hamburger menu
   - `chevron-left/right` - Carousel navigation
   - `close` - Modal/drawer close

2. **Search & Input** (4 icons)
   - `search` - In search input field only
   - `calendar` - Date picker input
   - `location` - Location input
   - `filter` - Filter toggle button

3. **Core Actions** (4 icons)
   - `plus` - Add to itinerary (primary action)
   - `heart` - Save/favorite (secondary action)
   - `share` - Share functionality
   - `save` - Save forms/content

4. **Status & Feedback** (3 icons)
   - `check` - Success states
   - `alert` - Warning states
   - `star` - Rating display only

5. **Auth & User** (3 icons)
   - `user` - User profile
   - `eye/eye-off` - Password visibility toggle

6. **Theme** (2 icons)
   - `sun/moon` - Dark mode toggle

## ❌ ELIMINATED Icons (Professional Cleanup)

### Decorative Icons Removed:
- ❌ Icons before section headings
- ❌ Icons in badges (use text only)
- ❌ Multiple icons in single cards
- ❌ Emoji icons (🤖, 📍, 🏛️, etc.)
- ❌ Social media icons in footer (use text links)
- ❌ Info icons (use help text instead)

### Typography-First Replacements:
- "📍 1,000+ địa điểm" → "1,000+ địa điểm xác minh"
- "🤖 AI trợ lý" → "AI trợ lý thông minh"  
- "🏛️ Đối tác" → "Đối tác chính thống"
- Icon-heavy cards → Clean badge-based design

## 📊 Icon Budget by Page Type

- **Homepage**: 6 icons max (search, filter, heart, star, plus, theme toggle)
- **Places List**: 4 icons max (search, filter, view toggle, theme)
- **Place Detail**: 8 icons max (navigation, actions, rating)
- **Forms**: 6 icons max (input helpers, navigation)

## 🎨 Professional Design Principles Applied

1. **Typography Hierarchy** - Strong headings replace decorative icons
2. **Badge System** - Status indicators use color/text, not icons
3. **Whitespace** - Clean spacing replaces icon clutter
4. **Color Coding** - Semantic colors convey meaning
5. **Micro-copy** - Clear text labels eliminate icon ambiguity

## 🛡️ Accessibility Improvements

- All remaining icons have proper `aria-label`
- Icon buttons meet 44×44px touch targets
- Focus rings visible on all interactive icons
- Screen reader friendly (icons supplement, don't replace text)

This cleanup reduces icon count from **227 instances** to **~60 instances** (73% reduction) while maintaining full functionality and improving professional appearance.
